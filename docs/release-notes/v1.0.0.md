# HDnotes v1.0.0

Everynote가 **HDnotes**라는 새 이름과 새 디자인으로 다시 태어났습니다. 화면 구성과 메뉴, 아이콘을 삼성 노트(Windows) 사용 흐름에 맞게 새로 정리했고, 기존 기능은 모두 그대로 쓸 수 있습니다.

## 새 이름, 새 아이콘
- 앱 이름이 **HDnotes**로 바뀌었습니다. 초록색 바탕에 펼친 노트와 펜이 그려진 새 앱 아이콘을 씁니다.
- HDnotes는 Everynote와 따로 설치되는 새 앱입니다. 설치 위치는 `%LOCALAPPDATA%\Programs\HDnotes`, 문서 폴더는 `문서\HDnotes`, 설정은 `%LOCALAPPDATA%\HDnotes`입니다.
- Everynote(Windows·안드로이드)에서 만든 **백업 파일을 그대로 불러올 수 있습니다.** ⋮ 메뉴 > **모든 문서 복원**을 이용하세요. HDnotes에서 만든 백업도 Everynote와 HDnotes 안드로이드 앱에서 불러올 수 있습니다.

## 문서함
- 왼쪽 탐색 창: **모든 노트, 즐겨찾기, 최근 문서, 휴지통, 폴더**. 폴더마다 색 아이콘과 문서 개수가 보입니다. 창을 좁히면 ☰ 버튼으로 열고 닫습니다.
- 위쪽 버튼: **노트 작성, PDF 가져오기, 편집, 보기 방식**과 검색 창, ⋮ 메뉴(폴더 만들기 등).
- 정렬: **수정 날짜 순 / 열어본 날짜 순 / 이름 순**, 오름차순·내림차순 전환.
- **휴지통 화면**: 지운 문서를 지운 날짜와 함께 보여 주고, 문서를 눌러 **복원**하거나 **완전히 삭제**할 수 있습니다. ‘비우기’로 한 번에 비울 수 있습니다.
- 문서 카드가 같은 크기의 정사각형 썸네일로 정리됩니다. 위쪽의 ‘<’(상위 폴더) 버튼은 없어지고, 왼쪽 탐색 창의 폴더 목록으로 이동합니다.

## 노트 편집 화면
- 위쪽: **‹ 문서함으로**, 문서 이름, 그리고 **전체 화면 · 읽기 모드 · 페이지 관리 · 노트 스타일 · 삽입 · 공유 · 파일로 저장 · 인쇄 · 검색** 버튼. 창이 좁으면 글자는 숨고 아이콘만, 더 좁으면 일부 버튼이 ⋮ 메뉴로 들어갑니다.
- 오른쪽 **도구 모음**: 키보드(글상자), 펜, 형광펜, 지우개, 올가미, 실행 취소/다시 실행, 테이프, 텍스트 표시, 메모, 도형, 텍스트 선택, 북마크, 두 쪽 보기. ‘‹’ 버튼으로 접고 펼칠 수 있습니다.
- 도구 모음 위치는 맨 위 ⠿ 버튼으로 **오른쪽 · 왼쪽 · 아래 · 떠 있는 창** 중에서 고릅니다. 창이 아주 좁으면 자동으로 아래쪽에 놓입니다.
- **펜 설정 창**이 도구 모음 옆에 붙어 열립니다: 펜 종류, 굵기·투명도(− / + 버튼과 슬라이더), 색 23가지와 직접 고르기, ‘직선으로 그리기’, ‘손가락 필기’ 스위치, **플로팅 툴바 표시**.
- **지우개 설정 창**: 획 지우기 / 부분 지우기, 크기, ‘이 페이지 손글씨 모두 지우기’.
- **삽입** 메뉴: 사진·이미지, 스티커, 도형, 표, 동영상, 유튜브 링크, 그리고 메모·하이라이트.
- 페이지 번호가 화면 아래 가운데에 작게 표시되고, 확대/축소 버튼은 왼쪽 아래에 작게 놓입니다.

## 메뉴와 창
- 아이콘 전체를 HDnotes 안드로이드 앱과 같은 가는 선 스타일로 새로 그렸습니다.
- 메뉴와 확인 창의 모양을 새 디자인에 맞게 바꿨습니다. 선택 목록은 왼쪽에 동그란 선택 표시가 나옵니다.
