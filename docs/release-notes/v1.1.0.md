# HDnotes v1.1.0

## 휴대폰과 양방향 동기화 (같은 Wi-Fi · 핫스팟 · USB 테더링)
- **휴대폰 자동 찾기**: 도구 → ‘다른 기기와 동기화’를 열면 같은 네트워크에서 동기화 창이 열린 HDnotes 안드로이드 앱(v1.1.0 이상)을 찾아 주소를 채웁니다. 휴대폰 화면의 **코드 6자리만** 입력하면 됩니다. USB 테더링·휴대폰 핫스팟에서도 찾습니다. 찾지 못하면 ‘다시 찾기’를 누르거나 주소를 직접 입력하세요.
- **바뀐 쪽만 맞추기**: 지난번 동기화 이후 PC에서 바뀐 문서는 휴대폰으로, 휴대폰에서 바뀐 문서는 PC로, 한쪽에만 있는 새 문서는 다른 쪽으로 복사하도록 미리 골라 둡니다. 변경 없는 문서는 접어 둡니다.
- **양쪽에서 모두 바뀐 문서**는 노란색으로 표시하고 더 최신 쪽을 골라 둡니다. 문서마다 ‘PC → 휴대폰 / 휴대폰 → PC / 건너뛰기’를 바꿀 수 있고, ‘자동(권장) · 모두 PC → 휴대폰 · 모두 휴대폰 → PC’ 단추로 한 번에 바꿀 수 있습니다.
- 한쪽에서 지운 문서는 다시 살리지 않고 건너뜁니다(삭제는 전달하지 않음). 열려 있는 문서는 양쪽 모두 덮어쓰지 않습니다.
- 동기화 기록은 휴대폰마다 따로 이 PC에 저장됩니다. PC는 요청만 보내므로 Windows 방화벽 설정을 바꿀 필요가 없습니다.
