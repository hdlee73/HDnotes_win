# HDnotes v1.1.2

## 새 앱 아이콘
- 파란 바탕에 책갈피가 달린 노트와 펜으로 아이콘을 바꿨습니다. 안드로이드 버전과 같은 아이콘이며, 실행 파일·창·작업 표시줄·설치 마법사·웹 화면 탭 아이콘에 모두 적용됩니다.

## 전체 화면과 텍스트 상자
- 전체 화면이 삼성 노트처럼 바뀌었습니다. 위쪽 막대와 탭만 숨고 오른쪽 도구 모음은 그대로 남으며, 오른쪽 위 둥근 단추로 전체 화면을 끝냅니다.
- 키보드(텍스트) 단추를 누르면 펜·지우개처럼 도구 모음 옆에 ‘텍스트’ 패널이 붙어 열립니다. 텍스트 상자가 없을 때는 다음에 만들 상자의 글꼴·크기·색을 정합니다.
- 입력 중에 열린 텍스트 상자 옆을 누르면 새 빈 상자가 생기지 않고 상자만 닫힙니다. 저장된 상자 안쪽(가장자리 포함)을 누르면 그 상자가 다시 열립니다.
